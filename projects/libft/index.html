libft

My first C library: libc functions rewritten from scratch.

42 São Paulo · Solo · May 2026

Languages & tools

  • C
  • Make
  • ar (static libraries)

Overview

libft is a static library of 43 general-purpose functions, rewritten without the standard library: character checks, string and memory handling, number conversions, output to file descriptors, and a singly linked list. Later 42 projects, like ft_printf and get_next_line, build on it.

To get the behaviour right, I read the source of glibc, musl, FreeBSD's libc and Apple's libc, then wrote every function myself. AI helped write a test program, not the functions.

What's inside

  • Character checks ft_isalpha, ft_isdigit, ft_toupper and 4 more
  • Strings ft_strlcpy, ft_strnstr, ft_split, ft_strtrim, ft_strmapi and 9 more
  • Memory ft_memmove, ft_memcmp, ft_calloc and 4 more
  • Numbers & output ft_atoi, ft_itoa, ft_putnbr_fd and 3 more
  • Linked lists ft_lstnew, ft_lstadd_back, ft_lstclear, ft_lstmap and 5 more

What it shows

  • Manual memory management

    Allocating, and freeing everything already allocated when a later step fails, as in ft_split; overflow-safe ft_calloc. ft_split.c, ft_calloc.c

  • Pointers and raw memory

    Byte-level copies, including overlapping ranges, where memmove must copy backwards. ft_memcpy_memmove.c

  • Data structures and function pointers

    A generic linked list that takes callbacks to transform and free its content. ft_lstmap.c

  • Build tooling

    A Makefile that compiles with -Wall -Wextra -Werror and archives a static library. Makefile

  • Reading real-world code

    Studying four libc implementations to match edge cases, then writing my own versions.
