Overview

Mobiari replaces the stack of separate tools a Brazilian online store usually juggles. One inbox brings in WhatsApp, Instagram, site chat and e-mail, with an AI assistant that answers customers, builds carts and hands over to the team when a person is needed. Behind it sit orders, a point of sale, discounts, catalog, stock and purchasing, NF-e invoicing, an online store with its own theme editor, marketing posts and catalogs, visual automations, and a public API with signed webhooks.

It runs on a Rust backend split into 21 crates, a React web app, and native Android and iOS apps for merchants, deployed to AWS from GitHub Actions. The codebase is about 265,000 lines of Rust, 140,000 of TypeScript, and 70,000 of Kotlin and Swift.

What I built

I joined in August 2026, spent the first weeks reading the codebase, and have made 848 commits since September, across the backend, web app, mobile apps and infrastructure. The main pieces:

  • Backend architecture Split the monolithic backend into a Cargo workspace of 18 layered crates, where each crate only depends on the ones below it, so the compiler enforces the architecture.
  • Native mobile apps Started both merchant apps, Kotlin/Compose on Android and SwiftUI on iOS, and wrote about three quarters of their code: sign-in, store switching, the inbox, voice messages with a hold-to-record composer, bulk actions, saved views, AI summaries and push notifications.
  • Conversations and the AI assistant Voice note transcription, customer memory the assistant builds from conversations, handing a conversation back to the AI, follow-up sequences for stale leads, and selling tools inside the inbox.
  • Orders and shipping Partial shipments, kits that leave in several boxes, and stock holds that survive retries and refunds.

What it shows

  • Systems design in Rust

    A layered workspace where crate boundaries enforce dependencies, on axum, sqlx and PostgreSQL with 292 migrations.

  • Native mobile on two platforms

    The same product in Kotlin with Jetpack Compose and in Swift with SwiftUI, sharing an OpenAPI-generated client contract and error messages.

  • Applied AI

    An assistant that answers customers, builds carts, remembers facts and knows when to hand over, plus speech-to-text for voice notes.

  • Shipping to production

    CI that runs per area, deploys to AWS (Graviton, S3, CloudFront) from GitHub Actions, and traces requests with OpenTelemetry.

  • Agentic coding with Claude

    Shipping features faster with AI agents, reviewing AI-written code quickly and carefully, and learning how to steer agents into writing good code.
