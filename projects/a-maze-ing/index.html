Overview

A-Maze-ing reads a configuration file, generates a random but reproducible maze, writes it out with a hexadecimal wall encoding, and shows it in a terminal interface. Every maze has a closed-off "42" in its centre and comes in two modes: a perfect maze with exactly one path between any two cells, or a Pac-Man board with loops and no dead ends.

Generation is split in two: a generator (Wilson's algorithm or a recursive backtracker) builds a perfect maze, then a transformer braids it into a board. Both report every step they take, which the interface uses to replay how the maze was built. Mazes go up to 1500 × 1500 cells, built on a background thread with a progress bar and a memory cap, so a huge maze can't freeze the computer.

The generator is a standalone package, mazegen, built as a wheel and reusable without the interface. My part: the generation framework and Wilson's algorithm, the braiding transformer, the Textual interface, the Makefile and the packaging.

What it shows

  • Graph algorithms

    Wilson's loop-erased random walk, a depth-first backtracker kept iterative to avoid recursion limits, and a breadth-first search for the shortest path. wilsons.py, backtracker.py, Maze.solve()

  • Data modelling with bit flags

    Walls are IntFlag bits, so the output file is a direct dump and wall checks are bitwise operations. Direction

  • Extensible design

    Generators and transformers share a base class and step callbacks, so new algorithms plug in and the interface can replay any of them. algorithms.py, taint.py

  • Packaging a reusable library

    mazegen has no dependency on the interface and builds to a wheel with make build. pyproject.toml, MazeGen

  • Terminal interfaces and threading

    A Textual app that builds mazes on a daemon thread and only touches widgets through call_from_thread(). ui/app.py, building.py

  • Resource limits

    Caps the process's memory with setrlimit() and warns before oversized builds. ui/memory.py

  • Code quality and teamwork

    Fully typed, checked with mypy and flake8, 374 pytest tests, built with a teammate over git. tests/, Makefile
